# Moon Relics (Forge 1.20.1)

Контент:
- Руда лунного камня (обычная и глубинная), блок лунного камня, самоцвет
- Лунный клинок (подсветка и замедление цели), Лунная кирка
- Полный комплект брони: прыгучесть, ночное зрение и медленное падение; ночью ещё сила и регенерация
- Лунный посох: ПКМ даёт рывок вперёд и медленное падение (кулдаун 2 сек)
- Русский и английский языки

## Как получить .jar
**Через GitHub (проще всего с телефона):**
1. Создай репозиторий на github.com и загрузи в него всё содержимое этой папки (включая папку `.github`).
2. Вкладка Actions -> Build mod -> дождись зелёной галочки.
3. Открой запуск -> Artifacts -> moonrelics-jar -> скачай, внутри будет .jar.

**На компьютере:** Java 17 + Gradle 8.x, затем `gradle build`. Файл появится в `build/libs/`.

Нужен Minecraft 1.20.1 и Forge 47.3.0 или новее. Положи .jar в папку `mods`.
